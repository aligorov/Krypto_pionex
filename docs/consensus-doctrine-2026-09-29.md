# КОНСЕНСУС-ДОКТРИНА: 6 споров, дебат 3 раунда, единое мнение

Дата: 2026-09-29 (ночь). Процесс: 3 исследователя интернета (независимые источники: Kaminski&Lo, Daniel-Moskowitz, Barroso-Santa-Clara, George-Hwang, arXiv DGT 2506.11921, MDPI Taranto&Khan, Odean, Vanguard, OKX/Pionex доки, r/Pionex, CoinGlass) → дебат «оптимизатор прибыли» vs «риск-скептик» → перекрёстные опровержения → схождение. Критерий: максимум $/день на $829 при ненулевом счёте.

## Контекст-диагноз (принят обеими сторонами без спора)

Медиана уже кормит (11 побед дня, TP-харвест ночи +$2.44 за часы). Весь реальный минус — один хвост HBAR −$4.03 (80% минуса дня). n=21 статистически неотличим от монетки → edge НЕ доказан, доказываться будет объёмом (15–25 сделок/день → n=500 за месяц), а не размером ставки.

## ЕДИНОЕ МНЕНИЕ по 6 спорам

### C1. Геометрия
**Шаг 0.40–0.48%** (пол = 3.2× round-trip ≈ 0.45% на 5/2 bps; ниже 0.31% ЗАПРЕЩЁН — там жили все стоп-ауты майнинг-выборки; «10× издержек» и «золотой 2%» независимой поддержки не получили — вычеркнуты). **Спан 8–10%** (нейтралы), **10–12% для шортов** (буфер под медвежье ралли ~10%). **Уровней 18–22** ($8/уровень尊重). Жизнь бота — по событию (выход из диапазона), таймеров нет.

### C2. TP-политика
**Харвест 2% инвестиции = закрытие + немедленный реинвест слота в лучшего кандидата сканера** (это и есть «компаунд параллельным ботом» по Pionex). Живого прибыльного бота не пересобирать — докапитализация через invest_in. Не закрывать раньше **4 чистых циклов ИЛИ всплеска ATR >1.5× медианы** (что раньше). Компаунд работает ТОЛЬКО в связке с хвост-контролем (MDPI-условие).

### C3. Направление
**Лонги**: только СВЕЖИЕ пробои (возраст тренда ≤10 дней от пробоя, недельный TSMOM по знаку, вход у верха канала до 90% — опора George-Hwang 52WH); ADX — подтверждение, не триггер. Плечо 2x база / 3x свежим пробоям.
**Шорты**: НЕ на свежем импульсе вниз — после контр-ралли ≥5% или ≥3 дней (ретест), с **фандинг-гейтом** (funding ≥ −0.03%/8ч), **RSI-пол возвращён** (фильтр исчерпания ралли), плечо 2x, бюджет ≤25% флота, спан 10–12%. 5x — исключён до доказательства edge.

### C4. Занятость
Развёрнуто ~75% ($620): **8–10 слотов × $50–75**. Флэт → до 80% нейтрал-ядро. Подтверждённый тренд → до **40% направленных** (закрывается не более половины нейтралов; ядро ≥50% остаётся ВСЕГДА — защита от lag-ADX перегруза на развороте). Резерв 25% — фонд манёвра: ввод кластером **после пика волы** (RV разворачивается вниз 2 замера подряд), ≤50% резерва, только при просадке счёта <10%.

### C5. Стопы (самый большой разворот против текущего прода)
**Внутри диапазона — стопов НЕТ** (Kaminski&Lo: тайт-стопы на коротком горизонте вредны для mean-reversion; радар, режущий медианы −$0.4–0.7, — EV-отрицателен). Выход = что раньше из: **{−30% слота (P&L-бюджет); граница спана + max(1.5×ATR(1h), 1.5%)}**. Перед стопом — **один trailing-сдвиг** adjust_params (второй пробой = стоп). Исполнение — **защитный лимит** с капом проскальзывания ≤0.3% (урок HBAR «стоп догнали»). Блэклист символа после 2 стоп-аутов.

### C6. Плечо/резерв/транши
**5x — НИКОГДА** (ликвидация ≈ 20% движения; оба дебатёра сдали его после арифметики). Нейтралы 3x (4x — только $75+ слот, спан ≥10%, стоп-бюджет ≤30%). Лонги 2–3x, шорты 2x. Vol-scaling — регулятор. Транши — не стратегия: lump-sum вход; единственный долив +40% только трендовому слоту В ПЛЮСЕ (пирамидинг, не DCA-усреднение лузера). Kelly-рамка — после n≥100.
